## 📝 Descrição do Projeto
O **Drei QR Code Pro Next-Gen** é uma solução de engenharia de software de elite para geração e gerenciamento de QR Codes estilizados. Diferente de geradores convencionais, este projeto foi concebido sob a ótica de **Engenharia de Produto de Nível Global**, priorizando uma interface "Dopaminérgica" com foco em UI/UX Premium, Glassmorfismo e segurança rigorosa.

O sistema integra inovações como **QR Codes Dinâmicos**, que permitem a alteração do link de destino em tempo real sem a necessidade de uma nova impressão, e o **SafeScan**, uma camada de inteligência que analisa a segurança da URL antes mesmo da geração do código.

## 🚀 Tecnologias Utilizadas
*   **Frontend:** React 18, TypeScript (Tipagem Estrita)
*   **Estilização:** Tailwind CSS (Arquitetura Oklch), Framer Motion (Interações Surreais)
*   **Backend & Persistência:** Cloud Firestore (Real-time NoSQL), Firebase Auth (OAuth Google)
*   **Engine Gráfica:** qr-code-styling, html2canvas, jsPDF
*   **Build Tool:** Vite

## 📊 Inovações e Funcionalidades
O projeto implementa três pilares disruptivos que o posicionam acima das referências de mercado:

*   **Inovação 01: QR Code Dinâmico** – Redirecionamento inteligente via ID Curto armazenado no Firestore. Flexibilidade total para o usuário final.
*   **Inovação 02: SafeScan IA** – Analisador preventivo de segurança que detecta URLs suspeitas ou maliciosas, garantindo a integridade dos dados compartilhados.
*   **Inovação 03: Engine de Exportação Avançada** – Suporte multi-formato (PNG, SVG, PDF) com inclusão de **Molduras de Design (Templates)** com CTAs personalizadas.

## 🔧 Como Executar
1.  Clone este repositório.
2.  Instale as dependências: `npm install`.
3.  Configure as variáveis de ambiente do Firebase no arquivo `.env`.
4.  Inicie o servidor de desenvolvimento: `npm run dev`.
5.  Para produção: `npm run build`.

## 🧠 Aprendizados de Engenharia
*   **Clean Architecture:** Implementação de um store global (Zustand) modularizado e refatorado para escalabilidade.
*   **Segurança NIST/OWASP:** Configuração de regras granulares de Firestore para proteção de PII (Personally Identifiable Information).
*   **Performance:** Otimização de renderização de componentes RT (Real-time) com hooks customizados.
